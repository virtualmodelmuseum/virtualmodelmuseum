The browser cannot copy photos into your site folder automatically. This page will generate the exact folder and filenames; you then copy the photos there manually.

2. Description template

Write the English text first. Other languages can be filled later using the Caption Editor. Technical names, kit names and scales are stored separately and remain unchanged.

After exporting

  1. Copy the selected photos into:
    media/new_models/model-name/
  2. Put the downloaded posts-data.js into the assets folder and replace the old file.
  3. If you added translations, put translations-data.js into assets as well.
  4. Open index.html again.

Tip: keep photo filenames simple, for example 01-front.jpg, 02-side.jpg, 03-detail.jpg.
