Come applicarlo:
1. Estrai questo ZIP.
2. Copia la cartella assets nella cartella principale del sito.
3. Quando Windows chiede, scegli "Sostituisci i file nella destinazione".
4. Apri index.html in locale.
5. Seleziona IT e controlla i primi modelli dopo i Donati.
6. In GitHub Desktop:
   Summary: Add Italian captions batch 1
   Commit to main
   Push origin
